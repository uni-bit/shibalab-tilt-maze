# 勉強会(3)　ゲームにする

前回作った `game.js` に続きを書く。ファイルは作り直さない。

追加で使える関数

```
drawWall(x, y, w, h)   壁を描く。x, y は左上の角
drawGoal(x, y, r)      ゴールの穴を描く。x, y は中心、r は半径
```

STEP 1 から 4 までは全員やる。5 は自由。

---

## STEP 1　壁を置く

壁は何本も置くので、1つずつ変数を作らずに配列にまとめる。

```js
let walls = [
  { x: 0,  y: 120, w: 210, h: 16 },
  { x: 90, y: 250, w: 210, h: 16 },
];
```

`update()` の中で、配列の全要素を順に描く。

```js
for (let i = 0; i < walls.length; i++) {
  drawWall(walls[i].x, walls[i].y, walls[i].w, walls[i].h);
}
```

`walls.length` は要素数。`i` を 0 から 1 ずつ増やしながら、`walls[i]` で各要素を取り出している。

壁を増やしたいときは配列に `{ ... }` を足すだけでよく、`update()` 側は変えなくて済む。これが配列とループを使う理由。

**確認**　盤に壁が2本現れる。玉はまだすり抜ける。

## STEP 2　壁に当たり判定をつける

ここが一番難しい。順を追って進める。

### 2-1　当たっているかを調べる関数

`update()` の外に書く。

```js
function hitWall() {
  for (let i = 0; i < walls.length; i++) {
    let w = walls[i];
    if (ball.x > w.x && ball.x < w.x + w.w &&
        ball.y > w.y && ball.y < w.y + w.h) {
      return true;
    }
  }
  return false;
}
```

玉の座標が、壁の左端と右端の間にあり、かつ上端と下端の間にもあるなら、その壁の中にいる。`&&` は「かつ」。

1つでも当たっていれば `return true` で即座に抜ける。最後まで当たらなければ `false`。

### 2-2　めり込んだら戻す

考え方は、**x と y を別々に動かして、別々に判定する**。

これまでは x と y を同時に動かしていた。それを分ける。

```js
let prevX = ball.x;
ball.x = ball.x + ball.vx;
if (hitWall()) {
  ball.x = prevX;
  ball.vx = -ball.vx * 0.5;
}
```

x を動かす前の値を覚えておき、動かした結果が壁の中なら元に戻して反転する。

次に、同じことを y でやる。**ここは自分で書く。**

**なぜ分けるのか**　まとめて判定して両方戻すと、壁に沿って滑れなくなる。分けて処理すると、横壁に当たったときは縦方向の移動だけが残るので、壁を擦りながら進める。まとめた版も試して、動きの違いを確かめてみるとよい。

**確認**　玉が壁を通り抜けず、壁に沿って滑る。

## STEP 3　ゴールと、クリアの表示

### 3-1　ゴールを置く

```js
let goal = { x: 45, y: 330, r: 22 };
```

`update()` の中で描く。壁より先に書くと壁の下に隠れないので、`drawGoal` は `drawWall` より前に置く。

```js
drawGoal(goal.x, goal.y, goal.r);
```

### 3-2　入ったかを判定する

玉とゴールの中心の距離が、半径より小さければ入っている。距離は三平方の定理で求める。

```js
let dx = ball.x - goal.x;
let dy = ball.y - goal.y;
let dist = Math.sqrt(dx * dx + dy * dy);
```

`dist` が `goal.r` より小さければクリア。クリアしたかどうかを覚えておく変数を、ファイルの上の方に用意する。

```js
let cleared = false;
```

### 3-3　画面に出す

まず `index.html` に、メッセージを出す場所を1つ足す。中身は空でよい。

```html
<p id="message"></p>
```

`style.css` で見た目を決める。大きさ、色は自由。

そして `game.js` から書き換える。

```js
document.getElementById("message").textContent = "CLEAR";
```

`document.getElementById("message")` は、HTML の中から `id="message"` の要素を探して取ってくるという意味。`textContent` がその要素の文字。これに代入すると表示が変わる。

**HTML で置いた場所を、CSS で飾って、JavaScript で書き換える。** 3つのファイルが1つの機能でつながる。

**確認**　玉をゴールに入れると CLEAR と表示される。

## STEP 4　タイマー

`index.html` の `<p id="timer">` は、勉強会(1)で作ったまま `00.0` が固定表示されている。これを実際の経過時間にする。

やること

- ゲーム開始時刻を覚える。現在時刻は `Date.now()` でミリ秒で取れる
- 毎フレーム、開始からの経過秒を計算する
- `#timer` の `textContent` に入れる
- クリア後は止める

小数第1位までにするには `toFixed(1)` を使う。

```js
let sec = 12.3456;
sec.toFixed(1);   // "12.3"
```

STEP 3-3 と同じ書き方で要素を取得する。

**確認**　時間が進み、クリアで止まる。

## STEP 5　自由制作

ここから先は自分で決める。1つ以上やる。

**手をつけやすい**

- ステージを作り込む。壁を増やして迷路にする
- 色・タイトル・文字を変える
- 感度、反発係数、摩擦を調整して手触りを詰める
- クリア時のメッセージを凝る

**少し考える**

- ベストタイムを保存する（`localStorage.setItem` / `getItem`）
- 落ちるとスタートに戻される穴を作る
- 壁に当たった回数を数えて表示する
- 制限時間を設けて、超えたら失敗にする
- リトライボタンを作る（`addEventListener` で `click` を拾う）

**挑戦**

- ステージを配列で複数持ち、クリアで次に進む
- 玉を2つにして、両方ゴールさせるとクリア
- センサー値にローパスフィルタをかけて手ぶれを抑える
- 効果音を鳴らす（`new Audio()`）
